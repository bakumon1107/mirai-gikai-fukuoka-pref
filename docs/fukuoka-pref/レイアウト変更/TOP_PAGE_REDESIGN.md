# トップページ改修仕様（みらい議会＠福岡県）

Claude Code への引き継ぎ用。デザインの参照は同梱の `reference/top-desktop.html`（PC, 1280px）と `reference/top-mobile.html`（スマホ, 390px）。これらはデザインツールの書き出しで、`support.js` 参照や固定サイズ指定を含むため、そのまま使わず **見た目・文言・構造の参照** として扱うこと。実装は既存の Next.js リポジトリのコンポーネント・データ構造に合わせる。

---

## 1. 背景と目的

- 現行トップは「テーマ別の議案カード」が主役。しかし福岡県の議案は本文がネットに公開されず情報が薄く、多くが工事請負契約など暮らしとの距離が遠い。
- 一方、知事記者会見（ほぼ隔週）、委員会（閉会中も開催）、一般質問は中身が豊富なのに、トップでは小さな入口リンクしかない。
- 目的は2つ。
  1. **更新頻度の高い情報から順に並べ**、閉会中でも「動いている」サイトに見せる。
  2. **お堅くない、気軽に見に来られる**トーンにする（参考：みらい議会＠世田谷区 https://civictech-setagaya.org/ ）。

## 2. 基本方針

- セクション順は更新頻度の高い順：**知事会見 → 定例会 → 委員会 → 一般質問 → テーマ → 予算・議員・議案**。
- 定例会は「年4回の議会の本番」として位置づけを明示する（落としすぎない）。
- 見出しや議題は「問いかけ」の言い回しにする（例：「飲酒運転撲滅対策の推進状況について」→「飲酒運転をなくす取り組み、いまどこまで？」）。
- 議案は個別カードを並べず、件数の要約に留める。

## 3. ページ構成

### PC（参照: reference/top-desktop.html）

1. ヘッダー（ロゴ、グローバルナビ、検索）
2. ヒーロー：会期ステータス＋見出し＋**最新の知事会見カード**
3. 定例会の帯（年4回、4枚横並び）
4. 左2/3：委員会の最新の話し合い（カード4枚, 2×2）／右1/3：一般質問から（3件）
5. 気になるテーマから（6タイル横並び）
6. 下段3カード：議員から探す／県のお金（予算）／議案の件数要約
7. フッター注記

### スマホ（参照: reference/top-mobile.html）

1. ヘッダー（ロゴ、検索）
2. ヒーロー（見出し＋最新の知事会見カードを縦積み）
3. 定例会の帯（2×2）
4. 委員会の最新の話し合い（カード3枚, 縦積み）＋「委員会をぜんぶ見る」
5. 一般質問から（3件）
6. 気になるテーマから（3列×2行）
7. 小カード2枚：県のお金／議員から探す
8. フッター注記
9. **ボトムナビ固定**：ホーム／会見／委員会／定例会／予算

※ ナビの違いは意図的。PC は「一般質問」「議案」を独立項目として持つ。スマホは5枠に収めるため、議案と一般質問を「定例会」タブ（定例会一覧→各定例会の議案・一般質問）にまとめる。

## 4. セクション別仕様

### 4.1 グローバルナビ
- PC：ホーム／一般質問／委員会／議案／知事会見／予算。現在ページはティールの塗りピル。
- スマホ：ボトムナビ（高さ72px、5等分、アイコン＋ラベル）。`env(safe-area-inset-bottom)` を考慮。コンテンツ末尾がナビに隠れないよう下余白を確保。
- リンク先は既存ルートに合わせる（`/press-conferences`, `/committees`, `/sessions`, `/sessions/[id]/questions`, `/sessions/[id]/bills`, `/budget` など）。

### 4.2 ヒーロー
- ステータスピル2つ：
  - 会期状態（「いまは閉会中」／会期中なら「いま定例会中」）。既存の「本日は 閉会中」表示のロジックを流用。
  - 次の定例会（「次の定例会 ◯月◯日から」）。**日程データがなければピルを非表示**。デザイン上の `[開会日]` はプレースホルダ。
- 見出し：「福岡県、いま何が話されてる？」
- 説明文：「知事の記者会見は、だいたい2週に1回。県がいま力を入れていることが、いちばん早くわかります。」
- 知事会見カード：
  - 最新の会見1件。バッジ「知事会見」、日付（曜日付き）、「最新」タグ。
  - 話題を最大4件、番号付きリスト。各行は会見詳細ページの該当トピックへのリンク（アンカーがあれば）。
  - 話題の文言は **短い問いかけ／言い切り（全角20字前後）** に言い換えたもの（新規データ項目、§6参照）。未生成なら既存のトピック名をそのまま表示。
  - 下部に過去3回分の日付チップ＋「ぜんぶ見る」（`/press-conferences`）。

### 4.3 定例会の帯
- 見出し：「定例会は年4回。議会の本番です」／補足：「議案の採決と一般質問は定例会で。あいだの期間は委員会が開かれます。」
- 当年の定例会4回（2月・6月・9月・12月）をカード表示。状態は日付から算出：
  - `おわった`：閉会済み。リンク「議案・一般質問を見る」等。
  - `つぎはここ`：次に開会する回（紫枠で強調）。開会日を表示。
  - `いま開会中`：会期中。紫枠で強調し、タグは背景 `#CEC8EA`・文字 `#332E5E`。**会期中は強調を開会中の回だけにし、次の回は `これから` にする**（§4.8）。
  - `これから`：それ以降。前年同月の回に一般質問データがあれば「昨年の◯月を見る」リンク。
- 各カードの一行説明は定例会ごとの短い説明（2月＝「新しい年度の予算を決める」など）。固定文言で可。
- **定例会の実際の月・日程は県議会の公式日程で確認すること**（デザインの月はあくまで例）。

### 4.4 委員会の最新の話し合い
- 表示件数：PC 4件、スマホ 3件。
- 選定ルール：
  1. 委員会ごとに最新の開催回を取る（1委員会1枚）。
  2. **質疑がない、または発言数が少ない回（目安：10発言未満）は除外**し、その委員会の一つ前の回を候補にする。
  3. 開催日の新しい順に並べて上位N件。
- カードの項目：
  - 委員会名、開催日
  - 見出し：議題を問いかけにしたもの（新規, §6）
  - 数字チップ（任意）：その回で最も目を引く数値1つ（例「相談対応 年1万3,786件」）。**無ければチップごと非表示**。
  - 要約：1〜2文、全角80字程度（新規, §6）。既存の会議要約（報告内容＋委員の要望）から作る。
  - リンク「発言のやり取りを読む（N発言）」→ 既存の `/committees/[slug]/[id]/transcript`。
  - カード全体は会議詳細 `/committees/[slug]/[id]` へ。
- 下に「委員会をぜんぶ見る」（`/committees`）。

### 4.5 一般質問から
- 最新の定例会の一般質問から3件。出典ラベル「令和◯年◯月定例会より」を必ず表示。
- 各行：短い見出し＋「◯◯ 議員」。既存の `/questions/[id]` へリンク。
- 選定は当面、既存の並び順の先頭3件でよい（将来的にテーマ分散や数字入りを優先するロジックを検討）。

### 4.6 気になるテーマから
- 6テーマ：子育て・教育／福祉・医療／防災・安全／まち・交通／しごと・農業／観光・文化。
- タイルは漢字一文字（育・医・防・街・農・観）の角丸アイコン＋ラベル。色は紫・ベージュ・コーラルの3系統を交互に（アイコン背景：紫 `#DBD3F9`／ベージュ `#EAE6DD`／コーラル `#FDE2D6`）。
- **リンク先（確定）：当面は検索ページ `/search?q=…` に飛ばす。** テーマページ（`/themes/[slug]`）は本タスクでは作らない。
  - 現行の検索は `q` の文字列をタイトル・要約に部分一致させる方式（`search-repository.ts`）。テーマ名「子育て・教育」をそのまま渡すとほぼヒットしないため、タイルごとに代表キーワードを持たせる：

    | タイル | `q` |
    |---|---|
    | 子育て・教育 | `子育て` |
    | 福祉・医療 | `医療` |
    | 防災・安全 | `防災` |
    | まち・交通 | `交通` |
    | しごと・農業 | `農業` |
    | 観光・文化 | `観光` |

  - 対応表はテーマ定義と同じ1か所に置く（後でテーマページに切り替えるとき、リンク先だけ差し替えられるように）。
  - 推奨（小改修・任意）：検索でスペース区切りを OR 検索にする（例 `子育て 教育 保育`）。実装できたら上表の `q` を複数語に広げる。
  - 検索対象は議案・一般質問・委員会・予算で、**知事会見は含まれない**。そのため、テーマ見出しの補足文は「テーマで横断検索できます」に変更する（デザインの「質問・委員会・議案をまとめて見られます」は使わない）。
- テーマページは §7-2 のテーマ体系の統一（全データへのテーマ付与）が済んでから別タスクで作る。画面は検索結果のタブ表示を流用できる想定。
- 注意：現行の分類は議案（「福祉・医療」「まちづくり・環境」…）と一般質問（「健康・医療」「防災・安全」「交通・まちづくり」…）でずれている。上記6テーマへの対応表をコード内に1か所で定義すること（§7 未決事項）。

### 4.7 下段
- PC：議員から探す（日替わり2〜3名＋「順番に評価の意味はありません」注記）／県のお金（`/budget`）／議案要約（件数チップ：条例・工事の契約・購入・計画など、「議案をぜんぶ見る」）。
- スマホ：県のお金／議員から探す の小カード2枚のみ。
- 議員一覧ページが未実装なら、議員カードは非表示にしてよい。

### 4.8 会期中モード（参照: 会期中モード 薄紫.dc.html）

9月定例会（9月9日〜10月16日）が開催中のため、**公開時点で会期中表示が必要**。閉会中だけ実装すると「いまは閉会中」という誤表示になるので、以下の2段階で進める。

**段階1（公開に必須）＝ 案1a：文言差し替え**
- レイアウトは閉会中デザインのまま。
- 会期ピル：「いま定例会中」（背景 `#CEC8EA`・文字 `#332E5E`・太字）。
- 2つ目のピル：「◯月定例会 ◯月◯日まで」（スマホは「◯月◯日まで」）。
- 定例会の帯：開会中の回を紫枠で強調し、タグは「いま開会中」（背景 `#CEC8EA`・文字 `#332E5E`）、説明文は「◯◯を審議中」、下段は「◯月◯日まで」。
- 会期中は **強調枠を開会中の回だけ** にする（次の回に「つぎはここ」を併記しない。次の回は「これから」）。
- スマホの委員会セクションの補足文「閉会中も、テーマごとに…」は会期中は非表示、または「定例会のあいだは、議案を委員会でくわしく審査します」に差し替える。

**段階2（デザイナー確認後）＝ 案1b：ヒーローを定例会に差し替え**
- ピル：「いま定例会中」＋会期（「9月9日〜10月16日」）。
- 見出し：「◯月定例会、いま何を決めてる？」／説明：「年4回の議会の本番。補正予算や条例は、この期間に採決されます。」
- 進み具合バー：「N日目／全M日」。日付から計算する。
- 右カード「会期の流れ」：開会 → 一般質問・代表質問 → 委員会で審査 → 採決・閉会。各行に日付を出し、終わった段階には「おわった」タグ、いまの段階には「いまここ」（面 `#F5F4FA`）を付ける。**段階ごとの日程データが無ければ行ごと非表示**にする（開会・閉会の2行だけでも成立させる）。
- その下に入口タイル2枚：「今回の議案 N件を審議中」（`/sessions/[id]/bills`）、「一般質問 N人が質問」（`/sessions/[id]/questions`）。件数が0または未取得のタイルは非表示。
- 知事会見はヒーローの直下に1行の帯で表示（日付＋先頭の話題＋「ほか◯件」＋「会見を見る」）。
- 定例会の帯以降は段階1と同じ。

**実装**
- 会期状態は既存の「本日は 閉会中」ロジックを流用して `closed | in_session` を返し、ヒーローのコンポーネントを切り替える。
- 必要なデータ：各定例会の開会日と閉会日（必須）。段階ごとの日程は任意。

### 4.9 フッター注記
「非公式サイトです。AIで整理した内容を含むため、正確な情報は公式資料でご確認ください。」既存の免責・About・FAQ・GitHubリンク等は現行どおり残す（トップ下部またはフッター）。

- 参照デザインの `top-desktop.html` / `top-mobile.html` はティール時代の配色。**色は本表を正**とし、会期中デザイン `会期中モード 薄紫.dc.html` の配色を参考にする。

## 6. 新規に必要なデータ項目（AI生成）

既存のAI要約パイプラインに出力項目を追加する想定。すべて **元の要約に書かれていない情報を足さない** ことをプロンプトで明示する。

| 対象 | 項目 | 形式 |
|---|---|---|
| 知事会見の各トピック | `headline_short` | 全角20字前後。問いかけ or 言い切り |
| 委員会の各会議 | `headline_question` | 代表議題を問いかけにしたもの、全角25字以内 |
| 委員会の各会議 | `highlight` | 最も目を引く数値を含む短句（任意, null可）、全角20字以内 |
| 委員会の各会議 | `summary_short` | 1〜2文、全角80字程度。報告内容＋委員の主な要望 |
| 委員会の各会議 | `utterance_count` | 既存の発言数（無ければ transcript から算出） |
| 一般質問 | `headline_short` | 既存タイトル流用可。数字があれば含める |

言い換えの例：
- 「一般社団法人九州観光機構の事業について」→「九州観光機構、今年は何をする？」
- 「中東情勢に伴う本県農林水産業への影響について」→「中東情勢、県の農業・漁業への影響は？」

## 8. 実装ステップ（推奨順）

1. デザイントークン・フォントの導入、共通カード／ピル／セクション見出しコンポーネント作成。

5. 委員会カード（選定ルール含む。新規AI項目が無い間は既存の議題名・要約の先頭を切り詰めて表示）。
6. 一般質問・テーマ・下段・フッター。旧トップの議案テーマ別一覧は議案一覧ページへ移し、トップから削除。
7. AI生成項目の追加（別PRでよい）。

## 9. 受け入れ基準

- PC 1280px／スマホ 390px で参照デザインと同じ構成・順序になっている。
- 閉会中の現在データで、ヒーローに最新の知事会見が表示される。
